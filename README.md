# Bakery Ordering App 🍞🛒  
A C++ application for ordering bakery products, built using **SFML**, **OOP principles**, and **design patterns** like **Builder** and **Factory**. The app allows users to add products to their cart, input their details, and place an order. It also includes **exception handling** to ensure smooth execution.  

## 🚀 Features  
✅ Add products to the cart using a **Factory Pattern**  
✅ Build structured `Client` objects using a **Builder Pattern**  
✅ Real-time cart updates and display  
✅ User input for **name, address, phone number, and email**  
✅ Order placement with a final summary  
✅ **Try-Catch Exception Handling** to manage invalid inputs gracefully  

## 🛠 Technologies & Concepts Used  
- **C++** (OOP, STL, Exception Handling)  
- **SFML** (for the graphical interface)  
- **Design Patterns:**  
  - **Factory Pattern** (for product creation)  
  - **Builder Pattern** (for constructing `Client` objects with flexible attributes)  
- **Try-Catch Exception Handling** (to prevent crashes and handle invalid data)  
- **CLion** (as the development environment)
